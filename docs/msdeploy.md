# svc-a deployment evidence — variant C (local-a / dev)

k8s-deploy-variant-C-ok

This document is the repository-side deployment-evidence contract for `svc-a`
in the "K8s deploy-evidence variant C" delivery. It records only what the
repository must provide and what the deployment evidence must look like for
review. It contains no executable code, manifest, deploy script, or workflow.

## Service identity

| field | value |
| --- | --- |
| service | `svc-a` |
| target | `local-a` |
| environment | `dev` |
| acceptance surface | `GET http://127.0.0.1:18798/` |
| expected response status | `200` |
| repository | `https://github.com/Neytronik/mockarty-row18-deploy-a.git` |

The acceptance surface is owned by the `local-a` target runtime. Its behaviour
is not defined, served, or simulated by this repository.

## Deployer identity

Deployment to `local-a` in `dev` and the post-deploy health checks are
performed by the **Mockarty deploy node** after this commit is accepted. The
deployment must not be performed manually: no manual `ssh`, `kubectl`, `helm`,
or equivalent deploy action is part of this delivery.

## Expected deployment receipt fields

The deploy node records a receipt per deployment. For review of the `svc-a`
deployment it must contain at least:

| field | meaning |
| --- | --- |
| `receipt_id` | unique identifier of the deployment receipt |
| `service` | `svc-a` |
| `commit_sha` | the exact delivered commit SHA that was deployed |
| `target` | `local-a` |
| `environment` | `dev` |
| `deployer_id` | identity attributable to the Mockarty deploy node |
| `deployment_status` | result of the deployment step |
| `health_window_status` | outcome of the post-deploy health window (expected green) |

Each health-check entry inside the receipt's health window must carry:

| field | meaning |
| --- | --- |
| `method` | HTTP method of the probe (expected `GET`) |
| `url` | probe target (expected `http://127.0.0.1:18798/`) |
| `expected_status` | expected HTTP status (expected `200`) |
| `observed_status` | status actually observed on the target |
| `observed_at` | timestamp of the observation |

A reviewable health window is green and includes an observed `200` for
`GET http://127.0.0.1:18798/`. The receipt `commit_sha` must equal the exact
commit delivered from this repository.

## Evidence ownership

The actual deployment receipt and post-deploy health window are produced and
stored by Mockarty-managed evidence. They are **not** generated by this
repository and are not committed here. This document only declares the
contract they must satisfy.

The only repository change delivered by this run is this file
(`docs/msdeploy.md`). No service code, manifest, runtime configuration, deploy
script, workflow, or other repository is modified. Deployment, health checking,
and receipt generation are performed after acceptance by the Mockarty deploy
